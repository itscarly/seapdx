# Coffee Guide Rules

- Reserve no more than $60 for whole-bean coffee.
- Buy two default bags total: one in Seattle and one in Portland.
- Prioritize Anchorhead for Seattle and Coava for Portland.
- Treat Olympia, Stumptown, and Heart as alternates only if skipping a default bag.
- Note roast style and best use: espresso, drip, or pour-over.
- Prefer closest useful branch over duplicate branch chasing.
