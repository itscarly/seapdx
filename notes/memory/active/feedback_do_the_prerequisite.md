If the user says "streamline Bainbridge to 3 hours and add social venues in the gap," the prerequisite is:
1. Shorten the Bainbridge event
2. THEN add social venues

Do not add the social venues and leave the Bainbridge event unchanged. The user should never have to say "you're joking me right?" because the work was done in the wrong order.

**Why:** Multiple times in this session I skipped to the output (adding new events) without doing the prerequisite (adjusting existing events). This produced overlapping calendar blocks and forced the user to catch my errors.

**How to apply:** Before any add/insert operation, ask: "Is there an existing thing that must be changed first to make space for this?" If yes, do that first. Do not proceed to the add until the prerequisite is done and verified.
