# Workflows

## Notes workflow

- Obsidian uses this `notes/` folder as the vault.
- Codex should update notes here when meaningful project changes are made.
- Small changes can go into [[Project Log]] only.
- Bigger changes can also get their own note and be linked from [[Home]].

## Recommended habit

- Keep the full project open in Codex.
- Keep only `notes/` open in Obsidian.
- Ask Codex to make project changes as usual.
- The project instructions now tell Codex to also update the notes.
